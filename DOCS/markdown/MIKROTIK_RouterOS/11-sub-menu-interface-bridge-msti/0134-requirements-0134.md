## Requirements 

IPv4 FastTrack is active if the following conditions are met: 

no mesh, metarouter interface configuration; 

- sniffer, torch, and traffic generator are not running; 

- "/tool mac-scan" is not actively used; 

- "/tool ip-scan" is not actively used; 

- FastPath and Route cache are enabled under IP/Settings (route cache condition does not apply to RouterOS v7 or newer); bridge FastPath is enabled if a connection is going over the bridge interface;
