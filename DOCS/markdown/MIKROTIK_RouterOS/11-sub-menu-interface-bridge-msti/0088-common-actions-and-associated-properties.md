Property Description<br>action  (action name; Default: acce Action to take if a packet is matched by the rule:<br>pt )<br>accept - accept the packet. A packet is not passed to the next firewall rule.<br>add-dst-to-address-list - add destination address to address list specified by address-list parameter<br>add-src-to-address-list - add source address to address list specified by address-list parameter<br>jump - jump to the user-defined chain specified by the value of jump-target parameter<br>log - add a message to the system log containing the following data: in-interface, out-interface, src-mac,<br>protocol, src-ip:port->dst-ip:port and length of the packet. After a packet is matched it is passed to the next<br>rule in the list, similar as  passthrough<br>passthrough - if a packet is matched by the rule, increase counter and go to next rule (useful for statistics)<br>return - passes control back to the chain from where the jump took place<br>address-list  (name; Default: ) Name of the address list to be used. Applicable if action is add-dst- to-address-list or add-src-to-address-list<br>address-list-timeout  (none- Time interval after which the address will be removed from the address list specified by address-list parameter.<br>dynamic | none-static | time;  Used in conjunction with add-dst-to-address-list or add-src-to-address-list actions<br>Default: none-dynamic )<br>Value of none-dynamic ( 00:00:00 ) will leave the address in the address list till reboot<br>Value of none-static will leave the address in the address list forever and will be included in the<br>configuration export/backup<br>jump-target  (name; Default: ) Name of the target chain to jump to. Applicable only if  action=jump<br>log  (yes | no; Default:  no ) Add a message to the system log containing the following data: in-interface, out-interface, src-mac, protocol, src-ip:<br>port->dst-ip:port, and length of the packet. Allows to log packets even if action is not " log ", useful for debugging<br>firewall.<br>log-prefix  (string; Default: ) Adds specified text at the beginning of every log message. Applicable if action=log  or  log=yes  configured.<br>**----- End of picture text -----**<br>
