## Hotspot 2.0 

Hotspot 2.0 is a specification developed and owned by the Wi-Fi Alliance. It was designed to enable a more cellular-like experience when connecting to WiFi networks. In the attempt to increase Wireless network security Hotspot 2.0 access points use mandatory WPA2 authentication. Hotspot 2.0 relies on Interworking as well as adds some of its own properties and procedures. 

Interworking profiles are implemented according to IEEE 802.11u and Hotspot 2.0 Release 1 specifications.
