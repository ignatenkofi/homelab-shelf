## Firewall 

Stateful filtering 

- Source and destination NAT 

- NAT helpers (h323, pptp, quake3, sip, ftp, irc, tftp) 

- Internal connection, routing and packet marks 

- Filtering by IP address and address range, port and port range, IP protocol, DSCP and many more Address lists 

- Custom Layer7 matcher 

- IPv6 support 

PCC - per connection classifier, used in load balancing configurations RAW filtering to bypass connection tracking.
