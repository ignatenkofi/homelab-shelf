## Find device location using Cell information 

On devices using the R11e-LTE International version card (wAP LTE kit) some extra information is provided under info command. 

```
  current-operator: 24701
               lac: 40
    current-cellid: 2514442
```

**----- Start of picture text -----**<br>
Property Description<br>current-operator  (integer; Default: ) Contains MCC and MNC. For example: current-operator: 24701 breaks to: MCC=247 MNC=01<br>lac  (integer; Default: ) location area code (LAC)<br>current-cellid  (integer; Default: ) Station identification number<br>**----- End of picture text -----**<br>

Values can be used to find location in databases: Cell Mapper
