## DNS Cache 

This menu provides two lists with DNS records stored on the server: 

- "/ip dns cache": this menu provides a list with cache DNS entries that RouterOS cache can reply with to client requests ; "/ip dns cache all ": This menu provides a complete list with all cached DNS records stored including also, for example, PTR records.

You can empty the DNS cache with the command: "/ip dns cache flush".
