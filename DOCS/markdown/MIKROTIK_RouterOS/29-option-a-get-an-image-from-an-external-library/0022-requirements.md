## Requirements 

The App system inherits the same requirements as the Container package: 

- Architecture Support: arm64, and x86 architectures 

- Container Package: Must be installed 

- Device Mode: Container mode must be enabled (requires physical access and device reset) External Storage: Highly recommended for optimal performance 

- Memory Requirements: Adequate RAM for container operations (16MB SPI flash devices may require external storage for images) Architecture Limitations: Devices with EN7562CT CPU (like hEX Refresh) are not supported
