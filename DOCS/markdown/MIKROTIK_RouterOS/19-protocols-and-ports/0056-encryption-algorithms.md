## Encryption algorithms 

RouterOS ESP supports various encryption and authentication algorithms. 

Authentication: 

MD5 SHA1 SHA2 (256-bit, 512-bit) 

Encryption: 

- AES - 128-bit, 192-bit, and 256-bit key AES-CBC, AES-CTR, and AES-GCM algorithms; Blowfish - added since v4.5 

- Twofish - added since v4.5 

- Camellia - 128-bit, 192-bit, and 256-bit key Camellia encryption algorithm added since v4.5 DES - 56-bit DES-CBC encryption algorithm; 

- 3DES - 168-bit DES encryption algorithm;
