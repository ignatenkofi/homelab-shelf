## CAPs: 

Enable CAP mode on each AP, specify which interface is connected to the CAPsMAN router 

```
/interface wireless cap
```

```
set discovery-interfaces=ether1 enabled=yes interfaces=wlan1
```

After CAPs are successfully connected to the CAPsMAN Router, two CAP interfaces will be dynamically created on the CAPsMAN Router. Both of these interfaces will get dynamically added as bridge ports on the same CAPsMAN Router due to explicitly selecting the bridge interface with da tapath.bridge=bridge1 and using the default CAPsMAN Forwarding Mode datapath.local-forwarding=no. Because of using a bridge with enabled vl an-filtering, both CAP interfaces will also show up in a bridge VLAN table.
