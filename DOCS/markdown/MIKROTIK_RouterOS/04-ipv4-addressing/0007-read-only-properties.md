## Read-only properties 

Property Description 

162 

actual-interface Actual interface on which address is set up. For example, if address was configured on ethernet interface and ethernet interface was (string) added to bridge, then actual interface is bridge not ethernet. dynamic (yes | Whether address is dynamically created. no) invalid (yes | Whether address is invalid. no) slave (yes | no) Whether address belongs to an interface which is a slave port to some other master interface. VRF (string) Indicates which VRF this IP address is associated with.
