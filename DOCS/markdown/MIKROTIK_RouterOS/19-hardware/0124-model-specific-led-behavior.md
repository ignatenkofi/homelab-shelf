## Model-specific LED behavior 

CRS112-8P-4S-IN, netPower 16P - All PoE LEDs flashing: wrong voltage PSU plugged into one of the ports. CRS320-8P-8B-4S+RM - Purple color LED - PoE-Out port state is powered-on, PD uses high voltage (802.3bt). Blinking Purple color triangle LED - PoE-Out port state is short-circuit or overload
