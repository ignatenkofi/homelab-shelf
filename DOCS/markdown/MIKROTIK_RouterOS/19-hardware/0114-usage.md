## Usage 

RouterOS provides an option to configure PoE-Out over Winbox, Webfig, and CLI, basic commands using the CLI are 

Property Description 

1728 

print () Prints PoE-Out related settings. export () export is displayed under `/interface ethernet` menu. monitor (string| interface) Shows poe-out-status of a specified port, or all ports with `/interface ethernet poe monitor [find]` command. power-cycle (duration:0..1m |; Default: Disables PoE-Out power for a specified period of time. 5s )
