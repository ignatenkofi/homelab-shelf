## General interface properties 

The speed-test is based on five configurable properties: 

address - IP address of host; 

connection-count - If a device has more than 20 cores - core count will be used (default is 20); password - Password for the remote device; test-duration - Duration for each test (By default: 5 tests * 10 sec duration + 1sec pause between each test = 55sec); user - Remote device username;
