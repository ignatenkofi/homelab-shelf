## Local Update 

Instead of connecting directly to MikroTik servers you can upload package files to one of your local RouterOS device, and use it as a local package server. 

Menu: /system package local-update 

**==> picture [516 x 91] intentionally omitted <==**

**----- Start of picture text -----**<br>
Command Description<br>download-all Downloads all compatible packages that are available on the local package server. Downloaded packages are saved in root directory.<br>download Downloads specific compatible packages that are available on the local package server. Downloaded packages are saved in root<br>directory.<br>refresh Refreshes/checks the list of available packages on the local package server.<br>**----- End of picture text -----**<br>

Server from which to get the package can be defined in system/package/local-update/ update-package-source/
