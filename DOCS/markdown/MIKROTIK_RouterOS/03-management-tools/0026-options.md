## Options 

Options that can be configured using a branding package: 

- Router name - branding package name, device identity and platform name in RouterOS, can only be one word, don't use spaces or special 

- characters; 

- Company URL - value that appears in the console when you connect to RouterOS device; 

- Manual URL - documentation link, which can be opened in WebFig; 

- ASCII Logo - a text logo that is shown when logging into the command line interface, i.e. Telnet, SSH, WinBox Terminal. A logo can be created in the branding maker or copied from any other plaintext editor. A logo height cannot be larger than 8 lines, width is not limited, but note that in a narr ow terminal window a logo might be distorted. 

- Hide "Mikrotik" from SNMP information - MikroTik name will be hidden in SNMP information; 

- Do not run script on install - do not run Default configuration script on branding package install; Hide Default configuration prompt - hide Default configuration prompt after configuration reset (available starting from RouterOS 7.15) Hide default caps-mode-script - hide default caps-mode-script (available starting from RouterOS 7.15)
