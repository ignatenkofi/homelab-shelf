## How to Purchase a RouterOS license key 

1.  Go to mikrotik.com and log in to your account. 

2.  Access the "Purchase a RouterOS License Key" Section. 

3.  Choose the desired license Key Level; 

4.  Select Key Type "License key"; 

5.  Enter License Key Information: Paste the Software ID of the device; 

6.  Select Optional Key Features: 

   - Choose any additional features you might need for your key. 

7.  Press the "Place key in the cart" button. 

8.  Click "Proceed to checkout" to complete your purchase.
