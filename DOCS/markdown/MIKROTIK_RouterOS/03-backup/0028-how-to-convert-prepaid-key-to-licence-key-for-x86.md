## How to Convert prepaid key to licence key for x86 

1.  Purchase a RouterOS Prepaid Key 

Log in to your mikrotik.com account. Purchase a RouterOS Prepaid key if you haven't already. 2.  Access the "Make a Key from Prepaid Key" Section 

Navigate to the "Make a key from prepaid key" section in your account. 

3.  Select and Convert the Prepaid Key 

Select the desired prepaid key from the list. Input the Software ID of the x86 device you need to license, or the Software ID of the router to upgrade the licence level.
