## Supported Devices 

- CRS326-24G-2S+: Supported only on Gigabit Ethernet ports. CRS328-24P-4S+: Supported only on Gigabit Ethernet ports. CRS317-1G-16S+: Supported on all ports. 

- CRS326-24S+2Q+: Supported on SFP+ and QSFP+ interfaces. CRS312-4C+8XG: Supported on all ports. 

- CRS318-16P-2S+: Supported only on Gigabit Ethernet ports. 

- CRS318-1Fi-15Fr-2S: Supported only on Gigabit Ethernet ports.
