## Configure bonding 

Configure bonding and assign slave interfaces in this setup it is selected as built in wlan1 interface, but it can be also ether interface in other kind of setups. 

- For bridge device - 1. Press on Bonding sub-menu; 2. Add new member with " + "; 3. Add interface members ( wlan1 and wlan60-station-1 ) to bonding interface as Slaves; 4. Add interface member wlan60-station-1 as Primary interface; 5. Choose Mode as active backup ; 6.  Apply configuration.
