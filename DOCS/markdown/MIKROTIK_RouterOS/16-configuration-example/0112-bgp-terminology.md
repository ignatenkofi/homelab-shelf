## BGP Terminology 

AS - Autonomous System 

ASN - Autonomous System Number 

NLRI - Network Layer Reachability Information is what is being exchanged between BGP peers and represents how to reach the prefixes. IGP - Interior Gateway Protocol 

EGP - Exterior Gateway protocol 

1010 

RR - Route reflector is the router in the BGP network that reflects advertisements to all the neighbors, avoiding the requirement for full BGP mesh. 

Route server - is the BGP router that does not participate in traffic forwarding. Routes are typically not even installed in the FIB. loopback address - a /32 address configured on a dummy bridge interface, that can act as a loopback.
