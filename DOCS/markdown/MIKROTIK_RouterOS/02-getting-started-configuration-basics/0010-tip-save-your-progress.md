## Tip: Save Your Progress 

After each major section, backup your configuration: 

CLI Method: 

```
/export file=backup-step3
```

WinBox Method: 

1.  Files menu → Backup 

2.  Name it clearly (e.g., "after-internet-setup") 

3.  Click Backup 

If something goes wrong, you can restore: FIles menu → Click on Backup file → Restore
