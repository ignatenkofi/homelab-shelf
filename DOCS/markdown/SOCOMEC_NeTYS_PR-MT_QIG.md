                                                  NeTYS PR-MT 1500VA USB LCD

NPR-1500-MT

 Strong points
- Профессиональные
интерактивные ИБП
- Решение по защите от перебоев
электропитания и изменений
напряжения
- Простота эксплуатации
- Упрощенное подключение
- Защита линий передачи данных

 General characteristics
- Корпус Minitower позволяет
размещать систему рядом с ИТ-
оборудованием.
- Система AVR (Automatic Voltage
Regulation — автоматическое
регулирование напряжения) с
синусоидальной волной.
- Панель управления с ЖК-
дисплеем.
- Программное обеспечение
LOCAL VIEW для локального
мониторинга ИБП.
- Устройство подавления помех в
линиях передачи данных NTP.
- до 6 выходных розеток ИБП.

Compliance with standards
- IEC/EN 62040-1, IEC/EN 62040-2
- AS 62040.1.1, AS 62040.1.2, AS
62040.2
- CE
- RCM (E2376)
